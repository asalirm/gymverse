# قوام · QAWAM

تطبيق تمارين عربي، داكن دائماً بألوان كحلية، ويدعم الاتجاه من اليمين لليسار (RTL). فيه برنامج التمارين، وتسجيل الأوزان أثناء التمرين، وتطورك، ومدرب شخصي.

## الأقسام
| التبويب | وش فيه |
|---|---|
| **الرئيسية** | التحية، وإنجاز الأسبوع (حلقة وشريط الأيام)، وملخص الدقايق والحجم والسعرات، وتمرين اليوم وزر البدء، والجدول الجاي، وآخر التمارين |
| **التمارين** | مكتبة فيها بحث، وفلتر حسب العضلة، وأسماء عربية، وصور توضيحية، والجولات والعدات، وآخر وزن، والراحة. كل تمرين يفتح صفحته: الإحصائيات، والعضلات، والتكنيك، وملاحظات الجهاز |
| **البرامج** | برنامجك الحالي بأيامه وزر بدء لكل يوم، وتعديل البرنامج، وبرامج جاهزة (بوش بول ليج بالسوبر ست، علوي/سفلي ٤ أيام) |
| **التمرين** | التمرين الحالي مفتوح وصوره ظاهرة، والباقي مطوي. فيه الجولات، وخانة "آخر مرة"، والوزن والعدات، ومؤقت الراحة، وإشارة التحسن، وإنهاء التمرين |
| **إحصائياتي** | عدد التمارين والحجم أسبوعياً أو شهرياً، والتقويم، وتطور الأوزان، والأرقام القياسية، والجولات لكل عضلة، والوزن والقياسات، وسجل التمارين |
| **المزيد** | الملف الشخصي (الاسم والوزن والطول والعمر والجنس)، وأيام التمرين، والمدرب، وصور أجهزة النادي، والنسخة الاحتياطية |

## الملفات
- `app/qawam.html`: التطبيق كامل في ملف واحد (HTML وCSS وJS بدون أي مكتبات)، وهو المصدر الوحيد للكود. الألوان كلها معرّفة في `:root` أول الملف.
- `docs/`: نسخة تتثبت على الجوال وتشتغل بدون نت (PWA)، وتتولد من الملف اللي فوق.
- `docs/img/`: صور التمارين التوضيحية، من [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) (ملكية عامة).
- `docs/icons/`: الأيقونة (`qawam.svg`) ونسخها PNG.
- `scripts/build-pwa.mjs`: يبني `docs/` من `app/qawam.html`.

## التشغيل
**داخل Claude:** افتح رابط التطبيق في Claude. البيانات تنحفظ في حسابك، وفيه المدرب، والصور تنحفظ في الحساب.

**على الجوال (تطبيق مثبت):**
```bash
node scripts/build-pwa.mjs    # بعد أي تعديل على app/qawam.html
```
1. GitHub Pages يرفع مجلد `docs/` تلقائياً من الفرع.
2. افتح https://asalirm.github.io/gymverse/ في Safari.
3. اضغط مشاركة، وبعدها "إضافة إلى الشاشة الرئيسية".
4. في هالنسخة البيانات تنحفظ في الجوال، والمدرب ما يشتغل.

**تشغيل محلي:**
```bash
node scripts/build-pwa.mjs
cd docs && python3 -m http.server 8080   # بعدها افتح http://localhost:8080
```

## الحسابات
- **اقتراح الوزن الجاي (Double progression):**
  - إذا كملت أعلى عدد عدات في كل الجولات، يقترح ترفع الوزن بمقدار الزيادة المحدد للتمرين.
  - إذا ما وصلت أقل عدد عدات مرتين ورا بعض بنفس الوزن، يقترح تخفف ١٠٪.
- **السعرات:** معادلة ميفلين (BMR) ÷ ٢٤ × MET 5 × عدد الساعات. وإذا ما فيه طول وعمر، تنحسب بالوزن بس.
- **الجولات لكل عضلة:** العضلة الأساسية تنحسب جولة كاملة، والمساندة نص جولة. النطاق المناسب ١٠–٢٠ جولة للعضلات الكبيرة، و٦–١٦ للصغيرة.
