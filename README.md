# gymverse

مشكلة في اجهزة التمارين

## دفتر الحديد

`app/iron-log.html` تطبيق ويب في صفحة وحدة لخطة بوش بول ليج بالسوبر ست:

- **اليوم**: يقترح التمرين الجاي حسب دورتك، وتسجل فيه الوزن والعدات لكل جولة، وفيه مؤقت راحة بعد كل سوبر ست.
- **التطور**: رسم لكل تمرين (القوة التقديرية، أعلى وزن، الحجم)، وأرقامك القياسية، وسجل كل الجلسات.
- **الخطة**: تعدّل الأيام والتمارين والجولات ونطاق العدات ومقدار زيادة الوزن، وتربط التمارين كسوبر ست أو تفكها.
- **اقتراح الوزن الجاي** (Double progression):
  - إذا كملت أعلى عدد عدات في كل الجولات، يقترح عليك ترفع الوزن بمقدار الزيادة المحدد للتمرين.
  - إذا ما وصلت أقل عدد عدات مرتين ورا بعض بنفس الوزن، يقترح تخفف الوزن ١٠٪.
  - غير كذا، يقول لك تثبت الوزن وتزيد عدة.

### الحفظ

- **داخل Claude**: البيانات محفوظة في حسابك، وما يقدر يقراها أحد غيرك.
- **إذا فتحت الملف مباشرة في المتصفح**: البيانات تنحفظ في المتصفح نفسه، فخذ نسخة احتياطية من تبويب الخطة.
